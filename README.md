## 🌱 Tentang Repo Ini

Repo ini adalah rumah digital komunitas coding IPOG. Di sini kita menyimpan:

- Catatan materi harian yang dibagikan di grup
- Latihan dan jawaban dari challenge mingguan
- Proyek kecil buatan anggota
- Panduan untuk anggota baru

Repo ini **bukan** tempat pamer kode yang sempurna. Kode yang berantakan, belum selesai, atau masih banyak error **boleh banget** ada di sini. Justru dari situlah kita belajar.

## 🙋 Untuk Siapa?

Repo ini cocok untuk kamu yang:

- Belum pernah ngoding sama sekali, dan penasaran
- Pernah coba belajar tapi berhenti di tengah jalan
- Mau belajar santai tanpa tekanan dan tanpa target ambisius
- Mau punya teman belajar yang saling bantu

Tidak perlu laptop mahal, tidak perlu background IT, dan tidak perlu jago matematika.

## 🧭 Prinsip Kita

1. **Tidak ada pertanyaan receh.** Semua orang pernah bingung di titik yang sama.
2. **Kritik kodenya, bukan orangnya.** Kita saling bantu, bukan saling menjatuhkan.
3. **Pelan-pelan tidak apa-apa.** Konsisten sedikit setiap hari lebih baik daripada ngebut lalu berhenti.
4. **Error adalah guru.** Pesan error bukan tanda kamu gagal, tapi petunjuk untuk belajar.
5. **Bikin sesuatu.** Teori penting, tapi paling cepat paham kalau langsung dipraktikkan.

## 🗓️ Apa yang Kita Lakukan

### Rutinitas Harian (Senin sampai Jumat)

Setiap hari ada **1 hal kecil** untuk dipelajari, cukup 2 menit baca:

| Hari | Isi |
|------|-----|
| Senin sampai Jumat | 1 syntax Python (satu konsep per hari) |
| Setiap hari | 1 ilmu pengetahuan seputar coding (istilah, tips, fakta menarik) |

Tidak ada kewajiban. Yang mau ikut menjawab atau mencoba, silakan. Yang cuma membaca juga tidak masalah.

### Event Mingguan (Sabtu)

Event kecil sekitar 30 sampai 45 menit, formatnya bergilir:

- **Mini Challenge**: tugas kecil yang bisa selesai dalam 30 menit
- **Bedah Error**: belajar membaca dan memperbaiki pesan error
- **Show & Tell**: anggota menunjukkan apa yang sudah dibuat, sekecil apa pun
- **Tanya Jawab Bebas**: tanya apa saja seputar coding

## 📁 Struktur Repo

> Struktur ini bisa berkembang seiring waktu. Cek folder yang ada sebelum menambah file baru.

```
IPOG-Coding/
├── README.md              ← Halaman yang sedang kamu baca
├── materi/                ← Catatan materi harian
│   └── python/
├── latihan/               ← Latihan dan challenge mingguan
│   └── minggu-01/
├── proyek/                ← Proyek kecil buatan anggota
├── anggota/               ← Perkenalan anggota (opsional)
└── panduan/               ← Panduan teknis (setup, Git, dll.)
```

**Aturan penamaan sederhana:**

- Gunakan huruf kecil dan tanda hubung, contoh: `kalkulator-sederhana.py`
- Beri nama file yang menjelaskan isinya
- Hindari spasi di nama file atau folder

## 🚀 Mulai dari Sini

Ikuti langkah ini kalau kamu baru masuk. Tidak perlu semuanya hari ini, kerjakan satu per satu.

### Langkah 1: Buat akun GitHub

Daftar gratis di [github.com](https://github.com). Pilih username yang sopan dan mudah diingat, karena ini akan jadi "identitas coding" kamu.

### Langkah 2: Kenalan dengan repo ini

Baca README ini sampai selesai, lalu jelajahi folder `materi/` dan `latihan/` untuk lihat apa yang sudah ada.

### Langkah 3: Siapkan tempat ngoding

Pilih salah satu yang paling mudah buatmu:

- **Laptop/PC**: install Python dari [python.org](https://www.python.org/downloads/) dan editor seperti VS Code
- **HP**: lihat bagian [Ngoding dari HP](#-ngoding-dari-hp)
- **Tanpa install apa-apa**: gunakan editor online seperti Google Colab atau Replit

### Langkah 4: Coba kode pertamamu

Buat file bernama `halo.py`, isi dengan:

```python
print("Halo, IPOG Coding!")
```

Jalankan, lalu lihat hasilnya. Selamat, kamu sudah resmi ngoding! 🎉

### Langkah 5: Perkenalkan diri

Sapa di grup dan ceritakan: nama panggilan, pengalaman coding (nol juga tidak apa-apa), dan apa yang ingin kamu pelajari.

## 📱 Ngoding dari HP

Belum punya laptop? Tenang, kamu tetap bisa belajar dari HP. Salah satu opsi yang bisa dipakai:

- **Acode**: editor kode untuk Android yang ringan. Punya terminal bawaan sehingga kamu bisa menjalankan kode Python langsung dari aplikasinya.
- **Plugin Git di Acode**: memudahkan kamu menyimpan dan mengirim perubahan ke GitHub tanpa harus mengetik perintah terminal yang rumit.

Tips ngoding dari HP:

- Mulai dengan proyek kecil dan ringan
- Gunakan keyboard yang nyaman untuk mengetik simbol seperti `()`, `[]`, dan `""`
- Simpan pekerjaan sesering mungkin

Kalau ada kesulitan setup, tanya di grup. Kemungkinan besar ada yang pernah mengalami hal yang sama.

## 🤝 Cara Berkontribusi

Kamu boleh menambahkan latihan, catatan, atau proyek ke repo ini. Berikut alur sederhananya.

### Alur singkat

1. **Fork** repo ini ke akun GitHub kamu
2. **Buat branch** baru dengan nama yang jelas, misalnya `latihan-minggu-01-namamu`
3. **Tambahkan file** kamu di folder yang sesuai
4. **Commit** perubahan dengan pesan singkat, misalnya: `Tambah latihan minggu 1 - kalkulator`
5. **Push** ke repo hasil fork kamu
6. **Buka Pull Request** ke repo utama

Admin akan melihat dan memberi masukan. Kalau ada yang perlu diperbaiki, itu bukan penolakan, tapi bagian dari proses belajar.

### Yang boleh dikontribusikan

- Latihan dan jawaban challenge
- Catatan belajar dengan bahasamu sendiri
- Proyek kecil, sesederhana apa pun
- Perbaikan typo atau penjelasan yang kurang jelas
- Ide materi atau challenge baru

### Panduan pesan commit

Tulis singkat, jelas, dan menjelaskan apa yang berubah:

- ✅ `Tambah latihan perulangan for`
- ✅ `Perbaiki typo di materi variabel`
- ❌ `update`
- ❌ `asdfgh`

### Kontribusi pertamamu

Kalau ini pertama kalinya kamu memakai GitHub, mulai dari yang paling mudah: tambahkan file perkenalan singkat di folder `anggota/` dengan nama `namamu.md`. Itu sudah cukup sebagai latihan alur fork, commit, dan pull request.

## 🐍 Peta Belajar Python

Kita mulai dari Python karena sintaksnya mudah dibaca dan hasilnya cepat terlihat. Urutan di bawah ini hanya panduan, boleh dilewati atau diulang.

| Tahap | Topik | Contoh |
|-------|-------|--------|
| 1 | Output dan komentar | `print()`, `#` |
| 2 | Variabel | `nama = "Budi"` |
| 3 | Tipe data | teks, angka, boolean |
| 4 | Input dari pengguna | `input()` |
| 5 | Operator | `+`, `-`, `*`, `/`, `==` |
| 6 | Percabangan | `if`, `elif`, `else` |
| 7 | Perulangan | `for`, `while` |
| 8 | List | `buah = ["apel", "jeruk"]` |
| 9 | Dictionary | `{"nama": "Budi"}` |
| 10 | Fungsi | `def sapa():` |
| 11 | Mini proyek | kalkulator, kuis, to-do list |

## ❓ Cara Bertanya yang Baik

Pertanyaan yang jelas lebih cepat dijawab, dan membiasakan kamu berpikir seperti programmer. Gunakan template ini:

```
Mau bikin apa:
(contoh: program yang menghitung luas persegi)

Kode saya:
(tempel kodenya, bukan screenshot kalau bisa)

Error / hasil yang muncul:
(salin pesan errornya utuh)

Yang sudah saya coba:
(contoh: sudah cek ejaan, sudah coba ganti variabel)
```

Tidak perlu lengkap sempurna. Kalau belum yakin cara menjelaskannya, tulis saja apa adanya.

## 📜 Aturan Komunitas

1. Saling menghargai. Tidak ada merendahkan, mengejek, atau membandingkan antar anggota.
2. Kritik kodenya, bukan orangnya.
3. Tidak ada spam dan promosi tanpa izin admin.
4. Hindari debat "bahasa X lebih bagus dari Y". Setiap bahasa punya kegunaannya.
5. Bantu menjawab kalau kamu tahu, tapi jelaskan alasannya, bukan sekadar memberi kode jadi.
6. Jangan menyalin kode orang lain tanpa paham. Tanya kalau belum mengerti.
7. Jaga privasi. Jangan membagikan data pribadi, password, atau token di repo atau grup.
8. Kalau ada masalah, hubungi admin secara pribadi.

Aturan berlaku sama untuk semua orang, termasuk admin.

## 📚 Kamus Mini Git & GitHub

| Istilah | Artinya |
|---------|---------|
| **Repository (repo)** | Folder proyek yang dilacak oleh Git |
| **Git** | Alat untuk mencatat riwayat perubahan kode |
| **GitHub** | Website tempat menyimpan repo secara online |
| **Fork** | Menyalin repo orang lain ke akunmu |
| **Clone** | Mengunduh repo ke perangkatmu |
| **Branch** | Cabang kerja terpisah, supaya perubahanmu tidak mengganggu yang utama |
| **Commit** | Menyimpan satu set perubahan beserta catatannya |
| **Push** | Mengirim commit dari perangkatmu ke GitHub |
| **Pull Request (PR)** | Permintaan agar perubahanmu digabung ke repo utama |
| **Main** | Branch utama yang berisi versi resmi repo |

## 💬 FAQ

**Saya benar-benar nol, boleh ikut?**
Boleh banget. Repo ini memang dibuat untuk pemula.

**Harus ikut setiap hari?**
Tidak. Ikuti sesuai kemampuan waktumu. Materi tetap tersedia kapan saja.

**Saya takut kodenya salah atau jelek.**
Semua orang mulai dari kode yang berantakan. Yang penting kamu mencoba.

**Boleh ngoding dari HP?**
Boleh. Lihat bagian [Ngoding dari HP](#-ngoding-dari-hp).

**Apakah akan belajar bahasa selain Python?**
Untuk sekarang kita fokus ke Python. Ke depannya bisa ditambah sesuai minat anggota.

**Saya error terus, harus bagaimana?**
Salin pesan errornya, lalu bertanya di grup memakai template di atas. Kita bedah bareng.
